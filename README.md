# Geduld-inator

Patience (Klondike) en FreeCell in LEDJOCKEY-stijl. Elk spel is gegarandeerd uitspeelbaar.

**Speel / installeer:** https://jimmyhonderd.github.io/geduld-inator/

## Installeren op Android

1. Open de link hierboven in Chrome.
2. Tik op ⋮ (rechtsboven) → **App installeren**.
3. De app staat daarna tussen je apps, start schermvullend en werkt offline.

## Wat erin zit

- Patience met 1 of 3 kaarten trekken (standaard 3); elke verdeling wordt vooraf doorgerekend.
- FreeCell met de klassieke genummerde spellen 1–32000.
- Tikken of slepen, onbeperkt terug, opnieuw, automatisch afmaken (aan/uit), statistieken.
- Adaptief voor telefoon en tablet, staand en liggend.
